**🇬🇧 [English](#-english) | 🇸🇦 [العربية](#-العربية)**

---

## 🇬🇧 English

### Overview

A sophisticated banking website UI built with React, focusing on responsive financial/marketing pages: a home page, about, careers, security, and authentication (login/sign-up) pages, with smooth animations and a carousel.

**Live demo:** https://eng-molazem.github.io/Yourbank_Project/

### Tech Stack

| Component | Technology |
|---|---|
| Framework | React 19 + Vite |
| Routing | React Router |
| Animations | Framer Motion |
| Carousel | Swiper |
| Deployment | GitHub Pages (gh-pages) |

### Pages

- **Home** — landing page.
- **About** — company information.
- **Careers** — job opportunities.
- **Security** — security information for customers.
- **Login / Sign Up** — authentication pages.

### Project Structure

```
src/
  components/   Reusable UI components
  data/         Static data used across pages
  pages/        Home, About, Careers, Security, Login, SignUp
  routes.jsx    Application routes
  App.jsx       Root component
```

### Getting Started

```bash
npm install
npm run dev       # start the dev server
npm run build      # production build
npm run deploy      # deploy to GitHub Pages
```

## 🇸🇦 العربية

### نظرة عامة

واجهة موقع بنكي احترافية مبنية بـReact، تركّز على صفحات تسويقية/معلوماتية متجاوبة: الصفحة الرئيسية، من نحن، الوظائف، الأمان، وصفحات المصادقة (تسجيل الدخول/إنشاء حساب)، مع حركات سلسة وعارض شرائح (Carousel).

**عرض مباشر:** https://eng-molazem.github.io/Yourbank_Project/

### البنية التقنية

| المكوّن | التقنية |
|---|---|
| الإطار | React 19 + Vite |
| التوجيه | React Router |
| الحركات | Framer Motion |
| عارض الشرائح | Swiper |
| النشر | GitHub Pages (gh-pages) |

### الصفحات

- **الرئيسية** — صفحة الهبوط.
- **من نحن** — معلومات عن الشركة.
- **الوظائف** — فرص العمل المتاحة.
- **الأمان** — معلومات أمنية للعملاء.
- **تسجيل الدخول / إنشاء حساب** — صفحات المصادقة.

### بنية المشروع

```
src/
  components/   مكوّنات واجهة قابلة لإعادة الاستخدام
  data/         بيانات ثابتة تُستخدم عبر الصفحات
  pages/        الرئيسية، من نحن، الوظائف، الأمان، تسجيل الدخول، إنشاء حساب
  routes.jsx    مسارات التطبيق
  App.jsx       المكوّن الجذري
```
